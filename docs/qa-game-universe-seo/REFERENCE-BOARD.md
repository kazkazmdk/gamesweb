## Neon Drift — *Haruna Service Line*

**Fantasy:** Illegal score-attack at 02:00 after rain, connecting mountain hairpins, a sodium service pull-off, a short tunnel, and an industrial harbor edge.

| | |
| --- | --- |
| Palette | Wet blue-gray asphalt, navy sky, concrete, forest black-green. Lighting: sodium amber, headlight white, sparse convenience cyan. Magenta is livery, not the world. |
| Lighting | Pools on wet tarmac, lamps every few samples, tunnel sodium collars. |
| Materials | Wet asphalt, painted marks, steel barriers, glass, vegetation, reflective chevrons. |
| Architecture | Retaining walls, guardrails, utility poles, vending-lit service cubes, harbor cranes. |
| Props | Containers, chevrons, start lights, roadside bushes, tunnel portals. |
| Silhouette | Low car + roadside clutter; mountains only on ridge. |
| Camera | Tight chase; zones must read *inside* the frustum. |
| VFX | Tire marks, slip smoke, sodium flicker. |
| HUD | BANK / LIVE / combo. |
| Opening | Start lights + wet line. |
| Peak | Long slide through a named zone (tunnel / service / hairpin). |

**Refs (5+)**

1. *Initial D* / Mt. Haruna night photography (Jalopnik, Speedhunters) — wet mountain, fog, guardrails. Borrow: darkness + wet grip. Do not copy AE86 / Akina signage.
2. *Ridge Racer Type 4* night industrial — harbor edge as a *place*. Do not copy R4 neon overload.
3. Irohazaka night photography (VicariousGear) — unlit hairpins, rest-house sodium. Borrow: sparse light. Do not copy shrine tourism.
4. Speedhunters Usui rain — sopping asphalt reflections. Borrow: puddle language. Do not copy real car liveries.
5. Low three-quarter chase composition (touge stills) — camera sits in the road, not a skybox tour.

**Do not copy:** cyberpunk magenta cities, Tron grids, generic “neon void”.

| | |
| --- | --- |

| Lighting | High-key noon; hard shadows point the route. |

| Architecture | Four kits: HVAC/service, glass canyon, crane/construction, telecom tower. |
| Props | Units, billboards, antennae, start arch. |

| VFX | Dust on land, checkpoint flash. |
| HUD | SECTOR. |
| Opening | Start arch + HVAC. |
| Peak | Different kit than open (crane or mast). |

**Refs**

1. *Mirror’s Edge* (DICE, inspected rooftop stills / AWN interview) — white + one signal color. Borrow: readability. Do not copy Faith / The Shard / red-only runner.
2. *Celeste* mountain platforms — route as composition. Do not copy Madeline / snow.
3. Tokyo roof photography (ME art trip notes) — HVAC as identity. Do not copy real signage.
4. Levi Wells / Casa TO haze vs Velocity noon — we stay bleach-warm, not peach brutalism (that is Sky).
5. Side-scroll “read the line” composition — next ledge before the jump.

**Do not copy:** dark silhouette parkour, Knockout’s candy sky.

**Do not copy:** Neon’s navy asphalt, generic circle/triangle enemies as the *only* language.

**Do not copy:** Velocity’s ivory roofs or shared pale-blue sky family.

## Crowd Control — *Festival Boulevard*

**Fantasy:** Bright European city festival / marathon-route crowd spectacle. Gates are huge graphic decisions. Pack scale is absurdly readable.

| | |
| --- | --- |
| Palette | Daylight sky, cream road, green parks, warm facades, multi-color crowd. |
| Lighting | Open daylight; banners catch sun. |
| Materials | Stone facades, painted road, fabric banners, graphic gate panels. |
| Architecture | Boulevard, plaza, park, bridge, finish arena. |
| Props | Huge +N / ×N / tax signs, finish tower. |
| Silhouette | Pack mass ellipse + varied people; 10 vs 86 is a different picture. |
| Camera | Zoom-out with pack; gate dominates the decision frame. |
| VFX | Compression at gate, re-expansion after. |
| HUD | PACK. |
| Opening | `setPack(10)` small crew. |
| Peak | `setPack(86)` + `seekGate` huge signs. |

**Refs**

1. *Count Masters* / crowd runners — pack as the score. Do not copy their gate UI chrome.
2. *Crowd City* mass — screen-dominating horde. Do not copy io-game flatness.
3. Berlin Marathon photography (Getty / AFP 2025) — boulevard + gate landmark + crowd depth. Borrow: city as route. Do not copy Brandenburg Gate.
4. Festival banner / marathon arch materials — saturated fabric, not thin green bars.
5. Decision-frame composition: two giant signs, pack approaching.

**Do not copy:** flat runner slab, tiny arch bars as the only gate language.
